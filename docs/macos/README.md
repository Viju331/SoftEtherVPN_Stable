## 🚀 Quick Start

### For First-Time Users:
1. Read **[QUICKSTART_APPLE_SILICON.md](QUICKSTART_APPLE_SILICON.md)**
2. Run the automated setup script in `../../scripts/macos/setup_apple_silicon.sh`

### For Advanced Users:
1. Follow **[BUILD_MACOS_ARM64.md](BUILD_MACOS_ARM64.md)** for manual build
2. Create installers using scripts in `../../scripts/macos/`

### For GUI Users:
1. Read **[GUI_USER_GUIDE.md](GUI_USER_GUIDE.md)**
2. Use the GUI app in `../../macos/gui/vpn_manager_gui.py`
